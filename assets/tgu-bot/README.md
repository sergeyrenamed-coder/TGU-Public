# TGU Telegram bot image assets

This directory contains the monochrome 16:9 image set used by the RNMDSTORE Telegram bot.

Upload the 16 JPEG files from the **TGU-Bot-Images-Upload.zip** package into this directory without renaming them.

Required filenames:

- `01_WELCOME.jpg`
- `02_PRODUCT_CATALOG.jpg`
- `03_DOWNLOADS.jpg`
- `04_ANDROID.jpg`
- `05_WINDOWS.jpg`
- `06_SOURCE_CODE.jpg`
- `07_TGU_FREE.jpg`
- `08_TGU_PLUS.jpg`
- `09_EARLY_ACCESS.jpg`
- `10_RNMD_ID.jpg`
- `11_PENDING.jpg`
- `12_APPROVED.jpg`
- `13_DECLINED.jpg`
- `14_ADMIN_NOTIFICATIONS.jpg`
- `15_ADMIN_NOTIFICATION_BELL.jpg`
- `16_ADMIN_EMPTY_INBOX.jpg`

The bot loads images from:

`https://raw.githubusercontent.com/sergeyrenamed-coder/TGU-Public/main/assets/tgu-bot/`

The files are intentionally monochrome: black, white and grayscale only.

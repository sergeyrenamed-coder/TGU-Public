# Обновление TGU — 19 ноября 2026 года

## Android 0.9.8 · Fast Connect
- Приоритет **RU Verified** по результатам серверной проверки в РФ; окончательное решение всегда за локальной проверкой устройства.
- Быстрый выбор и подключение первого работоспособного upstream, без ожидания полного каталога.
- Фоновая подготовка до **5** резервных прокси; аварийное переподключение после повторной проверки резервов.
- Сохранена работа с MTProto / SOCKS5, диагностика и стандартный автоподбор при отсутствии подходящих RU-кандидатов.

**Обновление:** `versionCode 27`, тестовая подпись проекта остаётся прежней. Другие ключи подписи не поддерживают установку поверх существующей версии.

## Desktop 0.4.3 · Работа в трее
- RU Verified, Fast Connect, до пяти запасных прокси.
- Обновлённый интерфейс с чёрно-белой палитрой, сворачиваемым боковым меню и фирменной верхней панелью.
- RNMD ID: вход через Telegram, профиль, защищённое хранение авторизации.
- Закрытие крестиком или Alt+F4 теперь скрывает окно в системный трей, не прерывая работу локального движка. Правый клик по значку — меню «Открыть TGU» / «Полностью выйти».
- Портативная сборка Windows x64; приложение не подписано коммерческим сертификатом издателя.

Обе сборки предназначены для Telegram, не обеспечивают системного VPN. Работа прокси зависит от конкретной сети и оператора.

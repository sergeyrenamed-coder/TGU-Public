# TGU Android — неизменная подпись тестовых APK

При публикации Android APK **нельзя** использовать временный debug-ключ GitHub Actions: на каждом новом runner он может отличаться, и Android откажется обновлять уже установленный пакет (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`).

## Постоянный сертификат TGU Android 0.9.5+

Публичный отпечаток SHA-256 сертификата:

```text
16:DD:84:A2:36:98:8D:08:EA:13:6B:2F:0F:6D:1A:C4:03:7C:01:2F:BC:1C:9E:1E:F1:94:3A:21:85:A9:B3:C7
```

Приватный `tgu-debug.jks` **никогда не должен попадать в Git**. Храните резервную копию отдельно от репозитория, желательно в зашифрованном хранилище.

### Настройка GitHub Actions

Откройте **Settings → Secrets and variables → Actions → Repository secrets** в репозитории `TGU-Public`. Создайте две записи:

- `TGU_DEBUG_KEYSTORE_BASE64` — base64 содержимого оригинального `tgu-debug.jks` (без переносов строки).
- `TGU_DEBUG_KEYSTORE_PASSWORD` — пароль к этому файлу. Алиас ключа в хранилище: `tgu-debug`, пароль ключа совпадает с паролем хранилища.

Получить base64 в Windows PowerShell:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path '.\\tgu-debug.jks'))) | Set-Clipboard
```

Пароли и приватные ключи нельзя публиковать в Issues, логах, коммитах или документации.

### Автоматические проверки

- **TGU Releases** отказывается собирать публикацию Android, когда Secrets отсутствуют, повреждены или сертификат не совпадает с зафиксированным SHA-256.
- **TGU Android CI** запускает тесты без Secrets, но **не загружает APK** с временной подписью в артефакты для установки.
- Windows-релиз публикуется независимо от Android.
- Android `applicationId` остаётся `com.rnmd.tgu`; для версии `0.9.5` используется увеличенный `versionCode=24`.

### Переход с ранее установленной сборки

Сертификат уже установленного APK **нельзя заменить** при обычном обновлении. Если прежний APK был подписан временным debug-ключом, а его приватный ключ больше не доступен, однократно сохраните свои настройки/данные, затем удалите старую версию и установите APK с закреплённой подписью. Удаление приложения может стереть локальные прокси-профили и данные входа.

**После установки постоянной версии** последующие APK с этим же сертификатом и увеличенным `versionCode` будут обновляться поверх неё. Храните файл `tgu-debug.jks` и пароль в защищённой резервной копии: потеря приведёт к новой несовместимости.

# TGU Desktop

Клиент TGU для Windows 10/11. Текущая публичная ветка — **pre-DPI**: в ней нет заявлений или функций обхода DPI.

## Возможности

- Локальный MTProto-узел для Telegram на `127.0.0.1:1443`; системный VPN-адаптер не создаётся.
- Поддержка классических MTProto- и SOCKS5-upstream-профилей.
- Автоматический подбор и проверка маршрута, диагностика подключения к Telegram DC и автоматический failover.
- Локальное хранение секрета MTProto в Windows Credential Manager.
- Русскоязычный интерфейс с собственной верхней панелью окна.
- Кнопка закрытия скрывает приложение в системный трей; полное завершение доступно из меню значка TGU в трее.

## Сборка и запуск

Требуются Node.js 20+, стабильный Rust toolchain, Visual Studio Build Tools с компонентами C++ и зависимости Tauri 2 для Windows.

```powershell
npm install
npm run tauri dev
```

Проверка фронтенда:

```powershell
npm run build
```

Сборка Windows:

```powershell
npm run tauri build
```

## Ограничения

- TGU маршрутизирует только трафик Telegram через собственный локальный прокси, а не трафик всей системы.
- Доступность публичных прокси зависит от сети и может меняться.
- Подтверждение ответа Telegram DC не означает, что пользователь вошёл в Telegram.
- При смене upstream уже открытые TCP/WebSocket-сессии могут потребовать переподключения.
